  • Element Lab

    A growing set of WebGL scenes, each wrapped in a drop-in HTML tag. Write <lab-scene name="driftfield"> and it runs. So far there are five: a quarter-million particles simulated entirely on the GPU, a raymarched surface with no geometry in it at all, a noise-displaced mesh that rebuilds its own normals, an instanced field built to sit behind a headline, and an orrery that puts the planets where they actually are today using NASA/JPL orbital data.

    • Three.js
    • GLSL
    • Web Components

    Open the lab Source

  • LocalScribe

    A native macOS meeting recorder that captures microphone and system audio as separate tracks, then transcribes both on-device with whisper.cpp. Meetings stay on the Mac: no cloud transcription, analytics, telemetry, or remote database. The library includes local search, audio playback, bookmarks, timestamps, and five export formats.

    • Swift

  • Kiran's Paper

    A personal morning newspaper for a used Kindle. Each day a small service gathers weather, calendar, news, markets, sports and new releases, a local LLM picks and summarizes the stories, and the edition ships as a light EPUB styled for e-ink, with sports scores hidden until tapped. Docked at home, the same Kindle turns into a once-a-day e-ink dashboard that sleeps between refreshes.
